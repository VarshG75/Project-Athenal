# Project-Athenal
Privacy-preserving Federated Learning (FedAvg) framework for K-12 student-risk prediction using synthetic data. Implements an edge-ready XGBoost model (95.8% acc, 0.982 ROC-AUC), a custom behavioral Consistency Index, and SHAP explainability to enable decentralized, FERPA-compliant early intervention on low-resource hardware.
